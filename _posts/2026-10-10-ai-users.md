### Quick reminder of Generative AI (GenAI)

First things first, let's settle that computers work by processing 0s and 1s (numbers). Imagine it like a switch turned on (1) or turned off (0). By stacking sequences of 0s and 1s, computers can generate complex values (such as 3, 4, 9999, etc.), images, videos, words, and everything we've known so far.
Let's call this language of 0s and 1s "computer language".

These are examples of how some English words are represented in computer language.

| Word  | Computer language             |
| ----- | ----------------------------- |
| Blue  | 0010 1111 1000 0000 1110 1101 |
| Black | 0000 0000 0000 0000 0000 0000 |
| White | 1111 1111 1111 1111 1111 1111 |
| Three | 0011                          |


On top of that, we've built generative AI. Generative AI is built on mathematical probability.
Here's a quick example to illustrate it simply:
If someone says "1, 2, and ..."
What would you say?
Most probably, you'd say "3".
That's probability applied to AI. Based on a given input, AI guesses the next item that would most logically follow it.

> Sorry, expert folks — I say "logically" instead of "probabilistically" just to make the message easier to understand for ordinary people. The key message is: AI has been trained on historical human interactions, which makes AI's probability seem intuitively logical in the eyes of humans. Hence the "logically".

#### How does it happen?

Generative AI has a dictionary that allows it to understand any given input (such as a question) and guess the most logical output (an answer to the question).

Put simply, AI's dictionary is like a series of stacked filters. Each filter narrows down every possible answer to the point that there is only one possible answer that passes all of the filters.

Think about the time you bake a cake. You use a sieve to filter the flour, letting only the finest part pass through. AI works the same way, as shown in the illustration below. It filters values to generate what is most probably the right answer.

![Illustration of generative AI narrowing down possible answers like stacked filters](/assets/images/gen-ai-probability-tables.svg)

#### How does this translate to real life?

When filtering elements, we can't control which ones go through and which ones get filtered out. Hence, AI's answers are not always the same.
To the question "What is the weather today?"
The first time, AI might answer "The weather is sunny".
The second time, it might answer "The weather is cold but sunny".

This is what we call "probabilistic". It means AI is probabilistic because it guesses rather than thinks, unlike a human.

### How GenAI changes the future of digital tools?

Software is ubiquitous in our lives. Connected devices, smartphones, laptops, cars — everything runs on software.

Before Generative AI, software only did what it was asked to do. Click on "connect to my smartphone", and your car connects to your smartphone in a single click. Click on "update the inventory of factory A", and the system resynchronizes with its database to fetch the latest stock state.

With Generative AI, "connect to my smartphone" might lead to the removal of your smartphone from the car's list of trusted devices. "Update the inventory" might lead to data deletion.

#### What does this mean?

Software engineering used to be dictated by a sequence of instructions. At the end of the sequence, the output is **always** predictable, as in the following example.

```python
# Let's define 2 variables and their value
a = 2
b = 3

# The following will print "a + b = 5"
print ("a+b = ", a+b)

# Modify the value of one of the variables
a = 100

# The following will print "a + b = 103"
print ("a+b = ", a+b)
```

But with Generative AI, there is no guarantee of getting the same result across several executions. The same recipe does not always yield the same outcome, as the following example illustrates:

```
1. Generate a report on the latest inventory status

2. Update the inventory database of each factory
   
3. Generate a report on the latest inventory status
   
==> The 3rd instruction does not guarantee a report based on the updated information from the 2nd instruction.
```

Unlike classic software, AI-powered software is capable of much more complex tasks. AI can generate "creative" text, but it lacks the determinism that is key for critical systems, such as factories, or for "simple" tasks.

### The key takeaways

Does AI bring benefits to our lives?

The answer depends on two questions:
1. What is the use case?
2. What is the cost of a wrong answer?

Some examples are explained below.

| Use case                                    | AI                                                                                                                                                              | Classic software                                                                                                                                       |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Daily event notifications                    |                                                                                                                                                                   | Notifications are based on the event type, name, and time. Those parameters are clear enough for simple software to handle (unless you want to craft a personalized notification message). |
| Payment reminder for clients                  |                                                                                                                                                                   | The reminder is triggered by a specific date and time. Both parameters are fixed, which makes for a clear, reliable trigger.                            |
| Purchase suggestion for potential customers   | Suggestions are based on many parameters that AI can handle well. A wrong suggestion doesn't block users from buying — it only misses the opportunity to encourage an immediate purchase. |                                                                                                                                                           |
