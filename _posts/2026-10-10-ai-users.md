## Quick reminder of Generative AI (GenAI)

Source: TODO - anthropic article

First thing first, let's settle that computers work by processing 0 and 1 (numbers). Imagine it like a switch on (1) and switch off (0). By stacking series of 0 and 1, it can generate complex values (such as 3, 4, 9999, etc.), images, videos, words, and everything we've known so far.
Let's call this language of 0 and 1 as "computer language".

These are examples of how some English words are represented in computer language.

| Word  | Computer language             |
| ----- | ----------------------------- |
| Blue  | 0010 1111 1000 0000 1110 1101 |
| Black | 0000 0000 0000 0000 0000 0000 |
| White | 1111 1111 1111 1111 1111 1111 |
| Three | 0011                          |


On top of that, we've built a generative AI. Generative AI is built based on mathematical probability.
A quick example to put it in a simple image:
If one says "1, 2, and ..."
What would you say?
Most probably, you'll say "3".
That is probability applied to AI. Based on a previously given input, AI guesses the next one that would most logically go with the input.

> Sorry expert folks, I say "logically" instead of "probably" just to make the message more easily understandable by ordinary people. The key message, AI has been trained with historical contents of human interactions, which makes AI's probability seems intuitively logical in the eyes of human. Hence the "logically".

How does it happen ?

Generative AI has a dictionary that that allows it to understand any given input (such as a question) and guesses the most most logical output (an answer to the question).

Put simply, AI's dictionary is like a series of stacked filters. Each filter narrows down every possible answer to the point that there is only one possible answer that passes all of the filters.

Think of the time when you bake a cake. You use a sieve to filter out flour and let passing through only the most qualitative part. AI works the same way. It filters out values to generate what might most probably be the right answer.

How does it translate to real life ?

When filtering elements, we can't control which ones go through and which ones get filtered out. Hence, AI's answers are not always the same.
To the question "what is the weather today ?"
The first time, AI might answer "The weather is sunny".
The second time, it might answer "The weather is cold but sunny".

This is what we call "probabilistic". It means, AI is probabilistic because it guesses, not thinks like human.
## How GenAI changes the future of digital tools?

Software is ubiquitous in our life. Connected devices, smartphones, laptops, cars, everything run on software.

Before Generative AI, software does only what it is asked to do. "Connect to my smartphone", then your car connects to your smartphone in a single click. "Update the inventory of factory A", then the system resynchronizes with its database to fetch the latest state.

With Generative AI, "connect to my smartphone" might lead to the removal of your smartphone from the car's list of trusted devices. "Update the inventory" might lead to some data deletion.

What does this mean ?

Software engineering used to be dictated by a sequence of instructions. In the end of the sequence, the output is **always** predictable, like the following example.

```python
# Let's define 2 variables and their value
a = 2
b = 3

# The following will print "a + b = 5"
print ("a+b = ", a+b)

# Modify the value of one of the variables
a = 100

# The following will print "a + b = 103"
print ("a+b = ", a+b)
```

But in Generative AI, there is no guarantee in getting the same end result in each execution. The same recipe does not always yield the same outcome. The following example illustrates this :

```

1. Generate a report on the latest inventory status

2. Update the inventory database of each factory
   
3. Generate a report on the latest inventory status
   
==> The 3rd instruction does not guarantee a report based on the updated information from the 2nd instruction.

```

Compared to classic software, AI-powered software is capable of much more complex tasks. AI can generate "creative" texts, but it lacks of determinism that is crucial in lots of critical systems, such as in a factory, or for "simple" tasks.

## The key takeaways

Does AI bring benefits to our life ? 

The answer depends on two questions:
1. What is the use case ?
2. What is the cost of a wrong answer ?
