{%- comment -%} "Ask an AI" call to action: one box holding the instruction, the prompt and a copy button. Only the first line of the prompt is visible — the box clamps it in CSS rather than shortening it here, so the whole sentence stays in the markup. The copy button and any crawler get the full text while the box stays two short lines tall inside the hero. The instruction sits outside #ask-ai-prompt so it is never part of what gets copied. On a successful copy the script adds .is-copied to the box, which fades the contents out and the confirmation in. The confirmation is always present in the markup so aria-live can announce it when it appears.
